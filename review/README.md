# Core Knowledge Review

This directory completes the **Linux Essentials 010-160 / v1.6 Core track**.

The hands-on labs cover the command-line skills that benefit most from practice. This review closes the remaining objective coverage, especially Linux/open-source concepts, command discovery/help, operating-system and hardware concepts, and recognition items that do not justify a full terminal lab.

## Use this review in order

1. Read **[REVIEW.md](REVIEW.md)**.
2. Complete **[QUIZ.md](QUIZ.md)** without looking at the answers.
3. Check your work with **[ANSWERS.md](ANSWERS.md)**.
4. Revisit only the sections associated with missed questions.

The quiz contains **40 questions**. Its topic distribution mirrors the official v1.6 objective weights as a study device:

| Topic | Official total weight | Quiz questions |
|---|---:|---:|
| 1 — Linux Community and a Career in Open Source | 7 | 7 |
| 2 — Finding Your Way on a Linux System | 9 | 9 |
| 3 — The Power of the Command Line | 9 | 9 |
| 4 — The Linux Operating System | 8 | 8 |
| 5 — Security and File Permissions | 7 | 7 |
| **Total** | **40** | **40** |

The weights indicate relative exam importance; they do **not** guarantee that the real exam contains exactly this number of questions from each objective.
