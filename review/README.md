# Core Knowledge Review

This directory is part of the **Linux Essentials 010-160 Core track**.

It holds short review material for objectives that matter for the exam but do not justify a full terminal lab. The goal is to close objective coverage without turning recognition-heavy topics into artificial hands-on exercises.

Planned emphasis includes:

- Linux and open-source ecosystem concepts
- distribution families and package-manager recognition
- licensing and open-source organizations
- hardware and distribution-lifecycle recognition
- command discovery and documentation items that belong in 010-160
- any small objective-specific distinctions not already reinforced adequately by Core Labs 1–6

The Core track is not considered complete until this review material and the Capstone are built and tested.
